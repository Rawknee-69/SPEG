## Key Decisions

- **`@1jehuang/jcode-sdk` version → `^1.1.0` (spec said `^0.67.0`)** — `0.67.0` does not exist on the npm registry; only `1.0.0`, `1.0.1`, `1.1.0` are published (package first published 2026-08-03). Chose the latest GA release `^1.1.0`, consistent with the research intent ("GA TypeScript SDK, semver stable"). If a specific older API is required, revisit.
- **`tsconfig extends` → `../tsconfig.base.json` (spec said `../../`)** — `speg/` is a top-level workspace package (one level below repo root), unlike `packages/*` (two levels). `../../` resolves to `E:/SPEG/tsconfig.base.json` (outside the repo) and fails with `TS5083`. Confirmed convention against `scripts/` and `oxlint-plugin-t3code`, both top-level packages using `../`.
- **Subpath exports follow `@t3tools/shared` pattern** — each subpath is `{ "types": ..., "import": ... }`; `speg/src/index.ts` exists as an entry point but is intentionally NOT exported (no barrel export), matching the "subpath-only exports" requirement.
- **`private: true`** — matches the workspace package convention (`@t3tools/shared`, `@t3tools/contracts`); nothing in the plan publishes `@speg/core`.
- **`typecheck` script `tsgo --noEmit`** — matches the repo convention; `vp run --filter @speg/core typecheck` requires it.
- Kept pnpm's auto-added `minimumReleaseAgeExclude` entries and its YAML flow-style normalization in `pnpm-workspace.yaml` to avoid churn on the next install.
