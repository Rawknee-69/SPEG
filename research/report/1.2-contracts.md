## Key Decisions

- **Separate `SpegRpcGroup` instead of extending `WsRpcGroup`** — the task constraint "existing T3 Code contracts MUST NOT be modified — only new files added" makes extending `WsRpcGroup` (defined in the existing `rpc.ts`) impossible; a standalone group in a new file is also the cleaner composition (consumers can merge it into their own transport group). Documented on `SpegRpcGroup` in `spegRpc.ts`.
- **`speg.cacm.queryContext: ContextQuery → MemorySearchResult`** — kept exactly as specced even though the naming is slightly unusual (a CACM query resolved through the memory store); it is the task's explicit wire contract.
- **Test helper decodes the wire literal first, then asserts `encode ∘ decode = identity`** — `Schema.brand` produces nominal types (`string & Brand<...>`), so plain literals aren't assignable to `S["Type"]`; decoding wire-shaped literals is also the realistic arrival path.
- **`speg/` barrel is intentionally NOT exported from the package entry** — adding `export * from "./speg/index.ts"` to `src/index.ts` (or a `./speg` subpath in `package.json`) would modify existing files, which the task forbids. Follow-up: wire the barrel into the package entry when task 1.7 (SPEG server integration) lands.
- **Field defaults for ambiguous spec fields** — `message` in `SpegTurnRequest` is the plain message text (`Schema.String`); `metadata` is `Record<String, String>` and required (as specced); `toolCalls`/`usage`/collections are required arrays (empty = none); timestamps are ISO-8601 strings (`Schema.String`, same as `IsoDateTime`); `limit`/`recencyHours` reuse `PositiveInt`, counts reuse `NonNegativeInt`.
